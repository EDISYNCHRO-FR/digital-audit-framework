# Glossaire - Digital Audit Framework

Ce glossaire présente les principaux termes utilisés dans le cadre des diagnostics numériques EDISYNCHRO.

---

## Transformation numérique

La transformation numérique désigne l'amélioration des pratiques d'une entreprise grâce aux outils numériques.

Elle peut concerner :

- les processus internes ;
- les outils métiers ;
- la collaboration ;
- la relation client ;
- l'automatisation.

---

## Diagnostic numérique

Un diagnostic numérique consiste à analyser l'environnement numérique d'une entreprise afin d'identifier :

- les points forts ;
- les risques ;
- les opportunités d'amélioration ;
- les actions prioritaires.

---

## Maturité numérique

La maturité numérique mesure le niveau d'utilisation et d'organisation des outils numériques d'une entreprise.

Elle prend notamment en compte :

- les usages numériques ;
- les processus ;
- la sécurité ;
- l'automatisation ;
- la gestion des données.

---

## Cybersécurité

La cybersécurité regroupe les pratiques permettant de protéger :

- les systèmes informatiques ;
- les données ;
- les comptes utilisateurs ;
- les équipements ;
- les activités numériques.

---

## Gestion des accès

La gestion des accès correspond à l'organisation des droits accordés aux utilisateurs.

Elle comprend :

- la création des comptes ;
- la gestion des permissions ;
- la limitation des privilèges ;
- la suppression des accès inutiles.

---

## Authentification multifacteur (MFA)

L'authentification multifacteur ajoute une protection supplémentaire lors de la connexion.

Elle demande plusieurs éléments de vérification, par exemple :

- un mot de passe ;
- un code temporaire ;
- une validation sur un appareil.

---

## Automatisation

L'automatisation consiste à utiliser des outils numériques pour réaliser automatiquement certaines tâches répétitives.

Exemples :

- traitement de données ;
- notifications ;
- génération de documents ;
- synchronisation entre outils.

---

## Processus métier

Un processus métier représente une suite d'actions réalisées par une entreprise pour atteindre un objectif.

Exemples :

- gestion des commandes ;
- suivi client ;
- facturation ;
- traitement administratif.

---

## Outils métiers

Les outils métiers sont les logiciels utilisés quotidiennement par une entreprise pour exercer son activité.

Exemples :

- CRM ;
- ERP ;
- logiciels comptables ;
- outils collaboratifs.

---

## Données

Les données représentent les informations utilisées par une organisation.

Elles peuvent concerner :

- les clients ;
- les collaborateurs ;
- les opérations ;
- les documents internes.

---

## Sauvegarde

Une sauvegarde est une copie de données permettant de restaurer des informations après :

- une suppression accidentelle ;
- une panne ;
- une attaque informatique ;
- une erreur humaine.

---

## Plan d'action numérique

Le plan d'action numérique définit les améliorations prioritaires à mettre en œuvre après un diagnostic.

Il précise :

- les actions recommandées ;
- leur priorité ;
- les bénéfices attendus ;
- les étapes de réalisation.

---

## Indicateur de performance (KPI)

Un KPI est une mesure permettant de suivre l'évolution d'un objectif.

Exemples :

- temps économisé ;
- réduction des erreurs ;
- amélioration de la sécurité ;
- adoption d'un nouvel outil.

---

## TPE / PME

Les TPE et PME sont les petites et moyennes entreprises.

Le Digital Audit Framework est conçu pour répondre aux contraintes spécifiques de ces structures :

- ressources limitées ;
- besoin de simplicité ;
- recherche de gains rapides ;
- accompagnement adapté.

---

## Framework

Un framework est une méthode structurée composée de pratiques, outils et modèles permettant de réaliser une mission de manière cohérente.

Le Digital Audit Framework constitue le référentiel EDISYNCHRO pour structurer les diagnostics numériques.
